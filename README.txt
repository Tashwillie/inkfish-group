INKFISH GROUP WEBSITE - UPLOAD PACK
===================================

WHAT'S IN THIS ZIP
  index.html                     The homepage (one-page site)
  assets/css/style.css           All styling
  assets/js/main.js              Logo build animation, division hover effects, and the "Read Louis's story" pop-up
  assets/images/                 All logos and photographs used on the page

HOW TO UPLOAD
  1. Upload everything to the root of the Inkfish Group domain, keeping the folder structure exactly as it is.
  2. index.html must sit at the top level so it loads as the homepage.
  3. No build step, framework or database is needed. It is plain HTML, CSS and JavaScript.

IMAGES
  inkfish-diamond-mark.png       Inkfish diamond, used as a mask and coloured by the CSS (teal, orange, yellow)
  wordmark-*.png                 Logo wordmarks, also used as CSS masks so their colour is set in the stylesheet
  louis-sky-news.jpg             Our story section
  louis-childhood-home.jpg       Our story section and the personal note pop-up
  forder-house-brighton.jpg      Head office in the Contact section
  The main Inkfish mark in the hero is drawn in code (SVG inside index.html), not an image file.

FONTS
  Helvetica Neue / Helvetica / Arial (system fonts). No web fonts to install.

ALSO INCLUDED
  inkfish-group-single-file.html  The same page as one self-contained file, as a fallback or for previewing offline.

PREVIEWING BEFORE UPLOAD
  If index.html is opened by double-clicking it on a computer, the logos may not appear. This is a browser
  security rule for local files, not a fault in the site. The logos show normally once the files are on the web
  server. To preview locally, open inkfish-group-single-file.html instead, or run any local web server.
